# FRUITBOX+ Website

Welcome to the official repository for the **FRUITBOX+** website! This project is a simple, responsive website built using HTML, CSS, and Bootstrap. It showcases the products offered by FRUITBOX+ and provides information about the brand.

---

## 🚀 Features
- **Responsive Design**: Works seamlessly on all devices (desktop, tablet, mobile).
- **Product Showcase**: Displays details about the **Couple Box** and **Family Pack**.
- **Clean UI**: Modern and user-friendly interface.
- **Contact Information**: Easy access to contact details.

---

## 🛠️ Technologies Used
- **HTML5**: For structuring the website.
- **CSS3**: For styling and layout.
- **Bootstrap 5**: For responsive design and pre-built components.
- **Font Awesome**: For icons.

---

## 📂 Project Structure
- `index.html`: The main HTML file containing the website structure.
- **Images**: Placeholder images are used for now. Replace them with actual product images.
